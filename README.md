# 🦀 RustArena — Онлайн PvP Шутер в реальном времени

Многопользовательская браузерная 2D-арена с архитектурой **Клиент–Сервер**, написанная на **Rust** и **JavaScript**. Сервер обрабатывает физику полета пуль, коллизии и синхронизацию игроков со скоростью 30 тиков в секунду через WebSocket.

## 🚀 Технологический стек

* **Backend:** [Rust](https://rust-lang.org) (асинхронный движок `Tokio`, веб-сервер `Warp`, WebSockets, сериализация `Serde`)
* **Frontend:** Vanilla JavaScript (ES6+), HTML5 Canvas API, CSS3
* **Сборка:** Cargo

## ✨ Особенности игры

* **Мультиплеер в реальном времени:** мгновенная синхронизация движения и выстрелов между всеми подключенными игроками.
* **Авторитативный сервер на Rust:** вся физика, проверка попаданий, подсчет очков и респавн рассчитываются на стороне сервера.
* **Потокобезопасность:** использование `Arc<Mutex<GameState>>` и каналов рассылки `tokio::sync::broadcast`.

## 🛠️ Установка и запуск

1. Убедитесь, что у вас установлен **Rust и Cargo** ([скачать с официального сайта](https://rustup.rs)).
2. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com
   cd rust-arena
   ```
3. Скомпилируйте и запустите сервер в релизном режиме:
   ```bash
   cargo run --release
   ```
4. Откройте браузер и перейдите по адресу:
   ```text
   http://localhost:3030
   ```
   *(Чтобы протестировать игру вдвоем на одном ПК, откройте адрес в двух соседних вкладках).*

## 🎮 Управление

* **W, A, S, D** или **Стрелки** — перемещение по арене
* **Левая кнопка мыши (ЛКМ)** — выстрел в сторону курсора
